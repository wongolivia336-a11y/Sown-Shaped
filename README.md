# Sown & Shaped

An editorial, responsive storefront concept for everyday objects shaped from plant materials.

> Concept exploration. Products are not yet available for purchase.

## Local development

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```

The front-end prototype uses React, TypeScript and Vite. Product data lives in `src/data/products.ts` and all imagery is authored locally as SVG. The early access form is intentionally not connected to a mailing-list service and does not store addresses.
